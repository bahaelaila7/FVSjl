Plan

cycles × yr
Select an AOI, then add Thin/harvest or Plant actions (or leave empty to grow only) and Run. Actions apply to every plot in the AOI at their scheduled cycle.
Landscape harvest budget PPE
A landscape budget as part of the scenario (FVSjl): FVS-PPE picks which plots to cut each cycle, in priority order, to meet a target resource flow across the whole AOI. Preview shows what it would cut; Add as thin action puts the same budget into the plan (a Thin action with “PPE budget picks stands”), so it runs with the scenario.
